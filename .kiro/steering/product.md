# 产品：X 关注管理（Chrome 扩展）

帮用户找出自己关注的人里没有回关的，按粉丝数、关注时间筛选，然后**由用户亲手**逐个取关 / 关注。

## 核心原则（任何改动都不能违反）

1. **不替用户点 X 的按钮**：取关 / 关注只做“打开主页 + 高亮按钮”，点击必须是用户本人。
2. **不向 X 发任何额外请求**：只旁听网页自己已经发出的 GraphQL / 1.1 请求的返回。不调用 X 内部接口，不伪造请求头。
3. **数据只存本机**：`chrome.storage.local`，按登录账号分开存，不上传、不接第三方服务。
4. **X 改版时安全失效**：解析不到数据就什么都不做，绝不能误操作账号。

## 用户与场景

- 中文用户，界面和文案全部中文。
- 典型流程：扫描关注列表 →（可选）扫描粉丝列表 → 筛选“没回关 + 粉丝数 100~300 + 最近 N 天关注” → 全选 → 逐个取关。
- 白名单：大 V 等不回关也正常的人，不出现在筛选结果里。
- 黑名单：取关过的人自动加入；以后在 X 上看到他们的「关注」按钮加红框，打开主页顶部有红色提示。

## 已知限制

- X 不提供“何时关注某人”，安装前已关注的只能显示“安装前已关注”。
- 只支持电脑版 Chrome 上的 x.com / twitter.com。
